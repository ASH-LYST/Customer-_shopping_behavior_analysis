# Data Analytics Project

## Overview
This project focuses on performing end-to-end data analytics using Python, SQL, and Power BI. The workflow includes data loading, data cleaning, exploratory data analysis (EDA), SQL-based analysis, dashboard creation, and reporting. The goal of the project is to extract meaningful insights from raw data and present them in a clear and interactive format.

---

## Dataset
The dataset used in this project contains business/customer-related information used for analysis and visualization.

### Key Features
- Customer details
- Sales/Purchase information
- Product categories
- Ratings and reviews
- Transaction records

## Project Workflow

### 1. Data Loading
- Imported dataset using Python
- Connected Python with SQL database
- Loaded cleaned data into PostgreSQL/MySQL/SQL Server

### 2. Data Cleaning
- Handled missing values
- Removed duplicates
- Renamed columns
- Corrected data types
- Standardized formats

### 3. Exploratory Data Analysis (EDA)
- Analyzed trends and patterns
- Performed statistical summaries
- Created visualizations for insights
- Identified outliers and correlations

### 4. SQL Analysis
Executed SQL queries for:
- Customer analysis
- Sales analysis
- Aggregations and grouping
- Filtering and sorting
- Joins and CTEs
- Business insights extraction

### 5. Dashboard Creation
Built an interactive Power BI dashboard including:
- KPI cards
- Sales trends
- Customer behavior analysis
- Category-wise performance
- Interactive filters and slicers

### 6. Reporting
- Prepared analytical report with insights
- Created presentation slides using Gamma AI
- Summarized findings and recommendations
